Q1. Bank Account Withdrawal

Create a Promise for withdrawing money.

Conditions:

  • Account balance = Rs. 10,000
  • Withdrawal amount = Rs. 7,000
  • If balance is sufficient, resolve the Promise.
  • Otherwise, reject the Promise.
  • Use .then() and .catch() to display the result.

Answer:

      let accountBalance = 10000;
      let withdrawalAmount = 7000;

      let withdrawMoney = new Promise((resolve, reject) => {
        if (accountBalance >= withdrawalAmount) {
          resolve("withdrawl successful");
        } else {
          reject("insufficient balance");
        }
      });

      withdrawMoney
        .then((result) => {
          console.log(result);
        })
        .catch((error) => {
          console.log(error);
        });

Q2. Online Exam Result

Create a Promise that checks student results.

Conditions:

  • Marks 50 or above: Pass.
  • Marks below 50: Fail.
  • Marks greater than 100 or less than 0: Invalid marks.
  • Handle the result using .then() and .catch().

Answer:

        let marks = 75;
        let checkResult = new Promise((resolve, reject) => {
            if (marks > 100 || marks < 0) {
                return reject("Invalid");
            }
            if (marks >= 50) {
                resolve("Pass");
            } else {
                reject("Fail");
            }
        });

        checkResult.then((result) => {
            console.log(result);
        }).catch((error) => {
            console.log(error);
        });

Q4. Promise Chaining

Create a Promise that performs these operations:

Conditions:

  1. Start with a number: 10.
  2. Add 20
  3. Subtract 5
  4. Multiply the result by 2.
  5. Display the final result
  6. Handle the result using .then() and .catch().

Answer:

      let myPromise = new Promise((resolve, reject) => {
        resolve(10);
      });

      myPromise
        .then((result) => {
          return result + 20;
        })

        .then((result) => {
          return result * 2;
        })

        .then((result) => {
          return result - 5;
        })

        .then((result) => {
          console.log("Final Result:", result);
        })

        .catch((error) => {
          console.log(error);
        });
